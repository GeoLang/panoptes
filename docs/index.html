Features

🧠 Semantic Segmentation

  • Per-pixel classification
  • Multi-class output with confidence
  • ONNX Runtime inference
  • User-supplied .onnx model
  • Threshold heuristic for smoke tests

🛰️ Satellite Preprocessing

  • DN to top-of-atmosphere reflectance
  • DOS1 atmospheric correction
  • Brovey pan-sharpening
  • NDVI, NDWI, EVI, NBR, SAVI indices
  • Band compositing

🔄 Change Detection

  • Temporal image comparison
  • Before/after analysis
  • Change magnitude scoring
  • Multi-resolution comparison
  • GeoJSON change polygons

🖼️ Multi-Resolution Processing

  • Image pyramid generation
  • Scale-invariant detection
  • Sliding window with overlap
  • Configurable tile size
  • Efficient memory management

📐 Vector Output

  • Automatic polygonization
  • Douglas-Peucker simplification
  • GeoJSON export
  • class_id, area_px, confidence properties
  • Pixel-space coordinates, no CRS yet

📊 Quality Metrics

  • Intersection over Union (IoU)
  • Mean IoU across classes
  • Pixel accuracy scoring
  • Per-polygon confidence from the model
  • Evaluation against ground truth

☁️ Cloud Optimized GeoTIFF

  • COG tile-based reading
  • TIFF IFD and tile offset parsing
  • Overview pyramid levels
  • Local files only, no HTTP or S3 client
  • No geotransform parsing yet

🔀 Parallel Processing

  • Tile-parallel inference via rayon
  • Result aggregation across tiles
  • Configurable tile size and overlap
  • Single process, not a cluster

🔍 Explainability

  • Occlusion sensitivity maps
  • Saliency map from confidence
  • Per-pixel confidence maps
  • Heatmap overlay on the source image
  • Library only, no CLI command

Quick Start

# Segment an aerial image with your own ONNX model
panoptes segment --input image.tif --output buildings.geojson --model path/to/model.onnx

# Detect changes between two dates
panoptes change --before 2022.tif --after 2024.tif --output changes.geojson

# List catalog models (metadata only, no weights)
panoptes models

# Evaluate prediction accuracy
panoptes evaluate --prediction pred.tif --ground-truth gt.tif --num-classes 5
